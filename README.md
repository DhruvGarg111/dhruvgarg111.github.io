# Dhruvgarg111.github.io

Personal portfolio website.

Live site: `https://dhruvgarg111.github.io/`

## Edit

- Content: `assets/js/data.js`
- Behavior: `assets/js/main.js`
- Styles: `assets/css/styles.css`
- Markup/SEO: `index.html`
